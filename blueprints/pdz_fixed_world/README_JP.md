# PDZ Fixed World style pack

StructurizeのScan Toolで確定したPDZ独自部品だけを登録する。第三者JARから抽出したblueprintやNBTを、ライセンス確認なしに格納しない。

推奨階層:

- `infrastructure/roads/r1` 〜 `r5`
- `infrastructure/bridges`
- `infrastructure/tunnels`
- `infrastructure/rail`
- `buildings/civic`
- `buildings/residential`
- `buildings/market`
- `buildings/industrial`
- `buildings/transit`
- `decorations/lakeshore` 〜 `rust_null`
- `states/damaged`
- `states/restored`

最初の登録対象はLakeshore試作街区の住宅、商店、倉庫、A1道路部品、小橋とする。
