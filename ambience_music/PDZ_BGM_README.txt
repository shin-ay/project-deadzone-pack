PROJECT DEADZONE ORIGINAL SOUNDTRACK v0.1

This music pack contains twelve original, procedurally composed tracks created
for PROJECT DEADZONE. It does not contain copyrighted game or film music.

Scenes:
- main menu
- settlement
- city / general daytime exploration
- wilderness and rain
- desert / badlands / savanna
- ocean / beach / boating / fishing
- underground
- night
- combat
- boss combat

Ambience Mini controls:
- P: reload the music configuration in game
- End: pause/resume music
- Page Up: skip to another track in the active playlist
- Page Down: print the detected state to latest.log

Redistribution is permitted as part of PROJECT DEADZONE client packages.
