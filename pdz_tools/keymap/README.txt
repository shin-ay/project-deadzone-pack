PROJECT DEADZONE 推奨キー設定

- E: インベントリ / Tab: プレイヤー一覧 / Q: アイテムを捨てる
- R: リロード / V: 銃近接 / C: 伏せ・スライド
- B: バックパック / N: NVG / Middle Mouse: Ping
- M: JourneyMap 全画面マップ
- J: PDZ JOB / K: Class Profile / G: Mine and Slash / U: Recruits Team
- Caps Lock: Voice Chat
- Alt+A/D: Lean / Alt+B: 遠隔Storage / Ctrl+H: 身体画面
- 旧XaeroのM/Y/U/]割当を解除
- その他の個人設定（画質、音量、操作感）は維持
- 適用前のoptions.txtは同じ場所へバックアップ

Minecraftを完全終了してから、インスタンスフォルダを
APPLY_KEYMAP.batへドラッグ＆ドロップしてください。
