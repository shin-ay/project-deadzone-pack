# LC2H 4.1.0-BETA 採用レビュー

更新日: 2026-08-30

## 判定

**条件付き採用候補**。

PROJECT DEADZONEの実サーバーはすでにLC2H 3.5.0を使用している。今回の変更は新規導入ではなく、次の3ファイルを同時に更新する世代更新になる。

| コンポーネント | 現行 | 候補 |
|---|---:|---:|
| LC2H | 3.5.0 | 4.1.0-BETA |
| The Lost Cities | 7.4.13 | 7.5.2 |
| Quantified API | 2.1.0 | 2.2.0 |

Forge 47.4.10 / Minecraft 1.20.1は要求を満たす。Berezka API for Lost Citiesの宣言依存もLost Cities 7.5.2と矛盾しない。

## 隔離サーバー検証

検証先: `F:\minecraft_pj\PDZ\DEV\LC2H_4_1_SERVER_SMOKE`

- 専用サーバー起動成功。
- 既存スモークワールドの再読込成功。
- 新規チャンクをまとめて生成してもクラッシュなし。
- LC2H Critical Hooksは8/8登録、実際のworldgen時に8/8観測。
- 終了時にplanner、GPU cache、worldgen scopeが正常終了。
- KubeJS server scriptsは45/45、エラー0・警告0。

大量のチャンクを一度に生成した試験では約8.6秒の遅延警告が1回出た。通常プレイの指標ではないため、採用前に実クライアントで徒歩・車両移動の比較が必要。

## 採用前に必要な目視・マルチ確認

1. 既存生成済み都市との境界に段差・欠損・建物の切断がない。
2. 新規都市でLost Cities建物、Berezka構造、通常構造物が不自然に重ならない。
3. Dynamic Trees、道路、地下・軍事施設が都市計画に潰されない。
4. 2人以上で別方向へ高速移動してもTPS低下、チャンク待ち、ロールバックが許容範囲。
5. サーバー停止時にLC2Hが正常終了し、次回起動で都市が変化しない。

## 配布上の注意

LC2H 4.xはベータ。配布時は自己ホストしたJARではなく、CurseForgeの正規ファイル参照を使う。ライセンス表記には配布元ページと同梱ライセンスの差があるため、実際のPackwiz反映前に再確認する。
