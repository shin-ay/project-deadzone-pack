# PROJECT DEADZONE 次元素材・ワールド生成方針 2026-08-21

## 決定事項

- ネザーとエンドは攻略可能な次元として使用しない。
- 必須素材は通常住宅や村の雑多なLootへ混ぜず、施設攻略報酬へ移す。
- ネザー系素材はT1～T2の地下施設・軍事施設に限定する。
- エンド系素材はT3以降の深層地下施設・戦略軍事施設に限定する。
- エリトラ、ドラゴンの卵など次元固有のトロフィーは通常Lootへ入れない。

## Loot割り当て

### T1 地下・軍事補給

- 対象: Underground Bunkersの通常庫・補給庫、Jeff系の弾薬庫・装備庫・補給庫、軍事チェスト。
- 素材: ネザークォーツ、グロウストーンダスト、ネザーウォート、マグマクリーム。
- 用途: 初期工業、ポーション、熱源系の導入。

### T2 地下・軍事重要区画

- 対象: Underground Bunkersの宝物庫、Jeff系の資源庫・上位武器庫。
- 素材: ブレイズパウダー、ブレイズロッド、ガストの涙、少量のネザライトスクラップ、マグマクリーム。
- 用途: 高温加工、上位工業、T2装備のボトルネック解消。
- ネザライトスクラップは当たり枠であり、安定供給品にはしない。

### T3+ 深層地下・戦略軍事施設

- 対象: 古代都市、要塞系深層施設、Jeff系の異常物資庫・最上位武器庫。
- 素材: エンダーパール、コーラスフルーツ、焼いたコーラスフルーツ、エンドロッド、少量のシュルカーの殻・ドラゴンブレス。
- 用途: T3以降の異常技術、空間・輸送系、最上位クラフト。

## 生成密度

- Lost Cities: `cityChance 0.00055 -> 0.00040`（都市中心候補を約27%削減）。
- Jeff / Doomsday / ChaosZ / Underground Bunkers: Structure Setの間隔を約15%広げ、面積当たり候補をおおむね25%削減。
- Jeffのstarterbunkerは開始導線用なので変更しない。
- Towns and Towersの町: `spacing 48 -> 42`。塔・その他施設は増やさず、むしろ他の生成物と同様に間引く。
- バニラ村: 現行の `spacing 28 -> 24`。村の候補密度を約36%増加。

## 適用範囲

- Loot変更はサーバー再起動後に新しく生成・開封される対象チェストへ反映される。
- Structure SetとLost Citiesの密度変更は、新規ワールドまたは未生成チャンクにのみ反映される。
- 既に生成済みの建物や都市を削除・移動する処理ではない。

## テスト項目

1. 新規ワールドで `/locate structure #minecraft:village` とTowns and Towersの村を複数確認する。
2. 同じ距離を移動し、旧構成よりJeff/Doomsday系の連続生成が減っているか確認する。
3. T1地下・軍事施設の通常庫からT1ネザー素材が出ることを確認する。
4. T2宝物庫からブレイズ系素材、まれにネザライトスクラップが出ることを確認する。
5. T3深層施設からのみエンド系素材が出ることを確認する。
6. 普通の村・住宅チェストへネザー／エンド素材が混入していないことを確認する。
