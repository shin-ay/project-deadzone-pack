# PROJECT DEADZONE 統合仕様 実装記録 2026-08-30

## 今回の対象

「基礎はあるが、整理後の仕様へ統合されていなかった部分」をローカル本番環境へ接続した。
新しい成長通貨・独自クラス・独自GUIは追加せず、既存の M&S、JOB、Pufferfish Skills、FTB Quests、EasyNPC、Camp Shop を役割分担させる。

## 正式な責務

- **World Tier T0～T5**: Campからの距離。地域の敵レベル下限と構造物候補を担当する。
- **Story Unlock S0～S4**: ストーリー目標。Camp契約、発展条件、店の候補、物語コンテンツ解禁を担当する。
- **Threat T0～T5**: オンライン中の最高M&S Lvと死亡救済。敵圧を担当する。サーバー日数は表示だけに使う。
- **JOB**: プレイヤーの役割と昇格。M&S Ascendancyの基礎配分はJOBから自動同期し、プレイヤーが別クラスとして選ばない。
- **Talent**: 自由成長。取得上限はStory Unlockに同期するが、レシピそのものは原則ベースラインとして利用できる。

旧 `deadzone_world_tier` と `deadzone_tier_*` は既存ワールド互換のため残す。ただし意味はStory Unlockの互換ミラーであり、画面上でWorld Tierとは呼ばない。

## 接続した縦切りループ

### T0 / 最初の帰還

JOB選択 → 探索準備 → Gas Station確保 → 無線卓へ帰還。
燃料ルート、Story S1、Camp在庫更新までを一巡としてFTB無線局へ記録する。

### S1 / 守った場所を育てる

初回Camp襲撃を完了 → 生活供給 → Camp Lv1 → 無線卓へ帰還。
戦闘と生活の成果がCampサービスへ戻る一巡として記録する。

### S2 / 地域へ影響を返す

既存T2支援ルート → 既存勢力判断 → 無線卓へ帰還。
判断結果は既存の勢力・店・依頼データを使い、新しい評判ゲージは追加しない。

## 世界変化の接続

Story Unlockが変化した時だけ、既存Camp Shopの次回ローテーションを即時化し、オンラインプレイヤーの無線局FTB表示を再同期する。
物理構造物の常時監視やMobの境界消去は追加していないため、常時負荷は200tickごとの整数比較だけ。

## M&S表示整理

- クラス画面を `JOB基礎同期（自動）` と表示する。
- 手動クラス選択を使わない旨を表示する。
- JOB同期で使わない旧ファンタジー系統を `旧M&S系統（未使用）`、配下を `未使用ノード` と表示する。
- M&Sの内部Ascendancyデータ自体は、装備生成とJOB基礎同期を壊さないため削除していない。
- `Mage Circle` は既存の現代化名称 `共鳴領域` へ統一した。

## 段階テスト項目

1. 新規または既存プレイヤーで `/deadzone status` を開き、現在地World TとStory Sが別々に表示される。
2. Campから100m、700m、1500mの境界を越え、World Tだけが距離で変化する。
3. サーバー日数を進めてもStory SとThreatが日数だけでは増えない。
4. Gas Station確保後にCampへ戻り無線卓を開くと、T0縦切りとStory S1が同期される。
5. S1到達時にCamp Shopが次回表示で更新され、契約・Camp発展条件がS表記になる。
6. 初回襲撃完了、Camp Lv1成立、無線卓帰還でS1縦切りが完了する。
7. T2支援ルートと勢力判断後、無線卓帰還でS2縦切りが完了する。
8. M&S画面でクラス欄がJOB自動同期と表示され、JOB変更後も対応する基礎配分になる。
9. `/deadzoneprogression audit` でStory、Legacy Stage、Talent Gate、Recipe Stageの同期を確認する。
