# PROJECT DEADZONE / BOSS作戦資料 RC1

更新日: 2026-09-16

## 共通戦闘規格

- すべてのPDZ Bossは、画面上部の専用HPバー、固有名、現在のM&S Lv、発光する識別章を持つ。
- Boss Lvは遭遇時点のプレイヤーLv上限+2。プレイヤー上限は開始時Lv10で、Bossマイルストーンごとに10上昇し、最終上限はLv100。
- HPはM&SのBossレアリティを基準にし、近くの参加人数で1人1.00倍、2人1.50倍、3人1.90倍、4人2.20倍、5人以上2.50倍になる。
- 攻撃力の基礎値はM&S、装備銃、各MobのAIから算出されるため固定値ではない。Bossから受ける最終ダメージは通常構成で1Hit最大HPの30%、1秒合計38%、タンク構成で1Hit 22%、1秒合計30%が上限。AXELはさらに低い専用上限を使う。
- HP 66%と33%に段階ロックがあり、大ダメージ一発で複数フェーズを飛ばせない。
- `/deadzonebosstest probe` で最寄りBossの実HP、M&S Lv、Attack属性、人数補正、フェーズ、被ダメージ記録を確認できる。

## 外観について

今回のRCでは、通常Mobと同じ名前・装備のままにせず、固有名、専用武器、固定外装バリアント、背負い装備、空中識別章、HPバー、フェーズ演出を組み合わせた。Infectious等が元から持つ大型・機械・放射能モデルは再利用ではなくBoss用の基礎モデルとして採用している。

完全な独自3Dモデルがまだ必要なのは、人型BossのWHITE STITCH、CINDER、MARSHAL GRAVES、ECHO-7と最終Boss RELAY SHEPHERD。ゲームプレイ実装と切り離し、次のアート工程でGeckoLib対応モデルへ順次置換できる構造にしている。

## テスト手順

1. `/deadzonebosstest combat` でBoss 02～14を管理者の周囲へ配置する。
2. GUNSHOP枠のBRASS HOUNDで、Boss Bar、真鍮パック、弾薬セル2基、セル破壊、防護解除、66%/33%フェーズを確認する。
3. 各予告を見てから回避できること、遮蔽でECHO-7とGRAVESの標定を切れること、WHITE STITCHの治療を攻撃で止められることを確認する。
4. `/deadzonebosstest probe` で実HP・Lv・Attack属性・人数倍率を記録する。
5. `/deadzonebosstest cleanup` でテスト個体と一時オブジェクトを撤去する。
