# Dynamic Trees for Nature's Spirit 導入確認

## 追加MOD

- `dtnatures_spirit-1.20.1-forge-1.3-all.jar`
- クライアント・サーバーの両方に必要

## 確認手順

1. クライアントとサーバーを完全に再起動する。
2. 起動ログに `dtnatures_spirit 1.3` が表示されることを確認する。
3. 新規ワールド、またはまだ生成していないチャンクへ移動する。
4. Nature's Spiritのバイオームで幹が枝状に成長するDynamic Treeが生成されることを確認する。
5. 既存チャンクの木が普通の木のままでも異常ではない。
6. Lost Citiesの建築部品や公園に直接組み込まれた木は変換されない場合がある。

## 注意

- サーバーだけ、またはクライアントだけに導入するとMOD不一致で接続できない。
- 既存の木を一括変換する処理は実施しない。
