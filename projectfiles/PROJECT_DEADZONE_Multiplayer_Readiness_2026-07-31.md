# PROJECT DEADZONE マルチテスト手順

目的: 2人以上で、開始から探索・戦闘・帰還までの基本ループと同期を確認する。

## テスト前の準備

- 全員が同じForge 47.4.10、MOD、config、defaultconfigs、KubeJSを使用する。
- テスト用の新規ワールドを作る。
- クラッシュ時刻を記録し、終了後にホストと参加者の両方のログを保存する。
- 建物の改装・Loot量の細かな調整は、このマルチテスト後に行う。

## 1. 接続と初期スポーン

- [ ] ホストがエラーなくワールドへ入れる。
- [ ] 参加者がタイムアウトやMOD不一致なしで接続できる。
- [ ] 両プレイヤーがSurvivor Campへ安全に到着する。
- [ ] キャンプ本体、職員、警備兵が全員に表示される。
- [ ] 一度離れて戻っても、建物やNPCが消失・重複しない。

## 2. JOB・Starter Kit・スキル

- [ ] 各プレイヤーが別々のJOBを選択できる。
- [ ] JOBに対応するStarter Kitが各自へ1回だけ配布される。
- [ ] `/deadzoneready status` のJOB・Starter・Tier・初期スキルが正しい。
- [ ] TABでインベントリとステータス画面を開ける。
- [ ] Kでスキル画面を開ける。
- [ ] 獲得XP、Lv、ポイント、Perkがプレイヤーごとに独立する。
- [ ] World Tier未達の上位スキルを取得できない。
- [ ] 再ログイン後もJOB、XP、Lv、Perk、タグが維持される。

必要な場合のみ、OPが次を実行する。

```mcfunction
/deadzoneready resync_skills
```

## 3. キャンプNPC・取引・Buddy

- [ ] JOB管理官、Buddy担当、食料、医療、工具、衣料品NPCが正しい位置にいる。
- [ ] NPCごとの会話・取引画面が両プレイヤーで開く。
- [ ] moneyまたは物々交換で購入でき、在庫がプレイヤー間で不自然に複製されない。
- [ ] 商品プールが補充時にシャッフルされる。
- [ ] Buddyはプレイヤー1人につき1人だけ雇用できる。
- [ ] Buddyの追従、戦闘、蘇生・復帰、再ログイン後の所有者を確認する。

NPC再適用用コマンド:

```mcfunction
/reload
/function project_deadzone:basecamp/apply_staff_profiles
/function project_deadzone:basecamp/fix_staff_facing
/function project_deadzone:basecamp/apply_trade_economy
```

## 4. パーティーと表示UI

- [ ] パーティー作成・招待・脱退ができる。
- [ ] 名前、HP、JOB、Lv、装備強度、方向が相手ごとに正しく表示される。
- [ ] First Aidの部位HUDとTotal Weightが左下で重ならない。
- [ ] RPG HUD、Jade、銃HUD、ミニマップが互いに大きく重ならない。

## 5. Loot・重量・共有挙動

- [ ] 通常チェスト、Lootr、特殊収納に設定したカテゴリのLootが入る。
- [ ] Lootrは各プレイヤーが個別に取得できる。
- [ ] 同じ通常収納からアイテムが複製されない。
- [ ] money・coinsを探索で取得でき、クラフトでは量産できない。
- [ ] 重量値とペナルティがサーバー側でも一致する。
- [ ] Scavenger・Engineerの重量／車両運搬優位が本人だけへ適用される。

## 6. 戦闘・NPC勢力・World Tier

- [ ] Raiders、PMC、Survivorsが意図した敵対関係で戦う。
- [ ] 同じTierのNPCでも武器は候補から変化し、防具は役割ごとの統一セットになる。
- [ ] World Tier上昇後にNPCのHP、防御、武器、防具が変化する。
- [ ] 銃を持つNPCへ近接モーションが誤適用されない。
- [ ] NPCのダウン、追撃耐性、出血死亡、衛生兵による蘇生を確認する。
- [ ] NPCドロップが設定量で出て、装備一式を毎回落とさない。
- [ ] PvPまたは誤射時のFirst Aid部位ダメージと蘇生を確認する。

## 7. クエスト・進行同期

- [ ] メインクエストのタイトルと説明が日本語で表示される。
- [ ] 個人タスクとパーティー共有タスクの進行範囲が意図どおりである。
- [ ] 報酬を各プレイヤーが重複して受け取れない。
- [ ] World Tier解放、レシピ解放、上位Perk解放が全員へ同期する。
- [ ] 途中参加者と再ログインした参加者の進行が壊れない。

## 8. 長時間・移動テスト

- [ ] 2人で別方向へ移動し、同時チャンク生成を10分行う。
- [ ] 都市への接近、車両移動、銃撃戦でクラッシュしない。
- [ ] TPS低下、NPC停止、キャンプや建物の重複生成がない。
- [ ] 一度全員退出し、再接続後も状態が維持される。

## 即時中断する条件

- 接続できない、またはワールドへ入れない。
- JOB、スキル、World Tier、Buddy所有者が別プレイヤーと混線する。
- Starter Kitやクエスト報酬を無限取得できる。
- キャンプ、NPC、建物が消失または重複する。
- 移動中に再現性のあるクラッシュが起きる。
- Lootまたは重量がクライアントとサーバーで一致しない。

## 現在の既知ログ

- First Aidの `Missing a damage model` は、現ログではプレイヤー切断後だけに発生。プレイ中に出なければ経過観察。
- Sentry Mechanical Armの `NoSuchFieldException: recipes` は起動時に多数発生。対象MODのレシピを使う段階で別途互換対応する。
- Epic Fightの `OBBCollider` は外部イベント処理スレッドで発生。戦闘クラッシュやモーション欠落がなければ今回の基本ループは継続する。
- 一部車両・家具MOD由来のLoot／Advancement読込エラーはMOD同梱データ由来。PROJECT DEADZONE独自Lootの確認とは分けて記録する。

## 合格条件

2人が新規ワールドでキャンプへ到着し、別々のJOBを選び、Starter Kitとスキルを取得する。その後、NPC取引・Buddy雇用・Loot探索・戦闘・クエスト進行を行い、帰還と再ログイン後も各自の状態が維持されれば、基本マルチループ合格とする。
