# PROJECT DEADZONE 工業素材統合 v0.1

## 方針

共通工業素材は Immersive Engineering（IE）を代表アイテムとする。
Mekanism固有の鉱石（オスミウム、錫、フルオライト）や加工中間物、TFMG固有部品は統合対象外。

## 代表素材

| 素材 | 代表MOD | 統合範囲 |
|---|---|---|
| 鉛 | IE | 鉱石ドロップ、原石、インゴット、ナゲット、粉、板、保管ブロック |
| ウラン | IE | 鉱石ドロップ、原石、インゴット、ナゲット、粉、保管ブロック |
| ニッケル | IE | 鉱石ドロップ、原石、インゴット、ナゲット、板、保管ブロック |
| アルミニウム | IE | インゴット、ナゲット、板、保管ブロック |
| コンスタンタン | IE | インゴット、ナゲット、保管ブロック |
| 鋼鉄 | IE | インゴット、ナゲット、粉、板、保管ブロック |
| 鉄・銅の粉 | IE | Mekanism粉からIE粉へ統合 |
| 鉄板・銅板・金板 | IE | CreateのSheetをIE Plateへ統合 |

## 互換性

- レシピの入力と出力を代表素材へ置換する。
- 重複鉱石を採掘した場合もIE原石を落とす。
- 重複素材はJEIから隠すが、既存ワールドとの互換性のため登録自体は削除しない。
- Mekanismの結晶・破片・クランプ・汚れた粉など、鉱石処理ライン固有の中間物は残す。
