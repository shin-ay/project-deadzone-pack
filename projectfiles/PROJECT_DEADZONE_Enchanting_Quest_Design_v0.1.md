# PROJECT DEADZONE 装備強化・依頼システム v0.1

## 役割分担

- Mine and Slash: ドロップ装備のレア度、Affix、ランダム個性
- Apotheosis Enchantment Module: プレイヤーが狙って育てる設備強化
- TaCZ Enchantments Overhaul: 銃固有エンチャント
- EnchantmentControl: 最大レベル、禁止、抽出、互換管理
- Easy Magic / Easy Anvils: 再抽選と金床の操作性
- Enchantment Descriptions: 効果説明
- FTB Quests: メイン、チュートリアル、MOD進行
- Bountiful: キャンプと勢力拠点の反復依頼・物々交換
- Realm RPG Quests: 現地NPCから受ける短編依頼
- Average DPS: ボス戦のチーム評価

## 進行

1. T0: エンチャント台、通常本棚、低級エンチャント
2. T1: Hellshelf、銃固有エンチャント、Enchantment Library
3. T2: Seashelf、Deepshelf、抽出・移植設備
4. T3: 高Eterna/Arcana設備、高レベル本、ボス限定効果

ApotheosisのAdventure/Affix、Spawner、Potion、Garden、Villageは使用しない。
Affixとエンチャントは別レイヤーとして共存させる。

## 依頼報酬方針

- Common: 食料、水、包帯、弾薬素材、ラピス
- Uncommon: 工業中間素材、工具、通常エンチャント本
- Rare: 高級医療、銃用本、装備強化素材
- Epic: 高レベル本、施設専用素材、勢力固有装備
- Legendary: 幹部・ボス・長期依頼限定

無料ファーム化を避けるため、種やバニラ資源だけの納品は低評価とする。
